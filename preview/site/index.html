What this proves — and what it doesn't 
Proves: SVG design time → .oko display list → the same pure Rust core
that runs on the bare console can run in a browser as WASM, with the
same animation, flags, and key bindings — no V8 JS engine in the loop
for the UI itself, no DOM, no CSS.

Does not prove: a full browser. Terminals, feeds, and shell commands
live in oko's adapters (libc / PTY), which do not compile to WASM.
That half stays native. This preview is the display-list half only.
